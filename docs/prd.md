# Requirements Document

## 1. Application Overview

**Application Name**: AI-Powered Forex Signal Telegram Bot

**Description**: A production-ready Telegram bot that provides AI-driven forex trading signals, market analysis, and portfolio management. The bot operates entirely within Telegram using inline keyboard navigation, integrates multiple AI providers for analysis, supports premium subscriptions, and includes comprehensive admin management capabilities.

---

## 2. Users and Use Scenarios

**Target Users**:
- Forex traders seeking AI-powered trading signals
- Users interested in real-time market analysis and news
- Premium subscribers requiring advanced features
- System administrators managing bot operations

**Core Use Scenarios**:
- Receive AI-generated forex trading signals with entry/exit points
- Access multi-timeframe technical analysis across currency pairs
- Monitor trading sessions and market volatility
- Subscribe to premium plans for enhanced features
- Track signal history and portfolio performance

### 3.2 Functional Description

#### 3.2.1 Start Menu
- Display welcome message and main navigation menu
- Show all available features via inline keyboard buttons
- Include Home, Back, Refresh buttons for navigation

#### 3.2.2 Live Signals
- Display real-time forex trading signals generated by AI
- Show signal details: currency pair, direction (BUY/SELL/NO TRADE), entry price, stop loss, TP1, TP2
- Display confidence level, probability, risk score, risk/reward ratio, trade duration
- Include detailed AI reasoning for each signal
- Allow users to add signals to favorites

#### 3.2.3 AI Analysis
- Provide multi-timeframe technical analysis (M1, M5, M15, M30, H1, H4, D1)

- Display analysis results with AI-generated explanations

#### 3.2.4 Market Scanner
- Scan multiple currency pairs across selected timeframes
- Identify trading opportunities based on technical indicators
- Display scan results with signal strength and recommended actions
- Allow users to filter by timeframe and currency pair

#### 3.2.5 Trading Sessions
- Display current active trading session (Sydney, Tokyo, London, New York)
- Show session overlap periods with increased liquidity
- Use Africa/Addis_Ababa timezone (UTC+3) for session detection
- Highlight high-volatility periods

#### 3.2.6 Forex News
- Display latest forex-related news from integrated market data providers
- Show news sentiment analysis using Google Gemini API
- Allow users to filter news by currency or topic

#### 3.2.7 Economic Calendar
- Display upcoming economic events and their expected impact
- Show event time, currency affected, importance level
- Provide AI interpretation of calendar events using Google Gemini API

#### 3.2.8 Portfolio
- Track user's active and closed trades
- Display portfolio performance metrics: total profit/loss, win rate, average risk/reward
- Show individual trade details and outcomes

#### 3.2.9 Signal History
- Display past signals with outcomes (TP hit, SL hit, or ongoing)
- Allow filtering by date range, currency pair, and result
- Show historical performance statistics

#### 3.2.10 Favorites
- Display user's saved signals and currency pairs
- Allow quick access to favorite items

#### 3.2.11 Premium

- Display user information: username, subscription status, join date

#### 3.2.13 Settings

## 4. Business Rules and Logic

### 4.1 Signal Generation Logic
- Analyze market data across M1, M5, M15, M30, H1, H4, D1 timeframes
- Calculate technical indicators: EMA 20/50/200, RSI, MACD, ADX, ATR, Bollinger Bands, VWAP, Stochastic, Fibonacci levels
- Identify trend direction, support/resistance zones, market structure, liquidity zones, volume patterns, breakout/retest scenarios
- Use Groq API for fast multi-timeframe analysis and signal generation
- Use Google Gemini API for detailed reasoning and educational explanations
- Generate signal only when conditions meet predefined criteria
- Output BUY, SELL, or NO TRADE based on analysis
- Calculate entry price, stop loss, TP1, TP2, confidence level, probability, risk score, risk/reward ratio, trade duration
- Never force a trade when conditions are unfavorable

### 4.2 Trading Session Detection
- Use Africa/Addis_Ababa timezone (UTC+3) for all time calculations
- Detect active sessions: Sydney, Tokyo, London, New York
- Identify session overlap periods (e.g., London-New York overlap)
- Increase scan frequency during high-liquidity overlaps

### 4.3 Notification Rules
- Send notifications for: new signals, TP hit, SL hit, high volatility alerts, major news events
- Respect user notification preferences set in Settings
- Deliver notifications via Telegram messages

### 4.4 Premium Subscription Logic
- Validate payment before activating premium features
- Support payment methods: Stripe, PayPal, Telegram Stars, USDT, BTC, ETH
- Apply subscription duration based on selected plan: Monthly, Quarterly, Yearly, Lifetime
- Automatically expire premium access when subscription ends
- Allow coupon codes to apply discounts

### 4.5 Market Data Provider Logic
- Support interchangeable providers: TwelveData, Finnhub, Polygon, AlphaVantage, ForexRateAPI
- Fetch real-time and historical market data from configured provider
- Handle provider API failures with fallback mechanisms

### 4.6 Security and Authentication
- Use JWT for session management
- Implement role-based access control (RBAC) for admin features
- Apply rate limiting to prevent abuse
- Verify Telegram webhook signatures
- Store API keys (GROQ_API_KEY, GEMINI_API_KEY) only in environment variables
- Never hardcode secrets in code

### 4.7 Background Task Processing
- Use Celery for asynchronous task execution: signal generation, market scanning, notification delivery
- Schedule periodic tasks using APScheduler: session detection, news updates, economic calendar refresh
- Store task results in Redis for caching

## 5. Exception and Boundary Conditions

| Scenario | Handling |  
|----------|----------|  
| AI API failure (Groq or Gemini) | Log error, retry with exponential backoff, notify admin if persistent |  
| Market data provider unavailable | Switch to fallback provider, log incident |  
| Invalid user input | Display error message, prompt user to correct input |  
| Payment processing failure | Notify user, log transaction details, provide retry option |  
| Database connection loss | Retry connection, queue operations, alert admin |  
| Webhook verification failure | Reject request, log security event |  
| Rate limit exceeded | Return rate limit error, block further requests temporarily |  
| Signal generation timeout | Cancel task, log timeout, retry with adjusted parameters |  
| Premium subscription expired | Disable premium features, notify user to renew |  
| Admin command from non-admin user | Deny access, log unauthorized attempt |

## 6. Acceptance Criteria

1. User sends /start command and receives main menu with all navigation options displayed via inline keyboard buttons
2. User selects Live Signals and views AI-generated forex signal with entry, stop loss, TP1, TP2, confidence, probability, risk score, and detailed reasoning
3. User navigates to Premium menu, selects a subscription plan, completes payment via Stripe, and premium features are activated
4. Admin sends /admin command, accesses admin dashboard, and views user statistics, revenue analytics, and API health status
5. System generates new signal during London-New York session overlap, sends notification to subscribed users, and logs signal in database

## 7. Out of Scope for This Release

- Automated trade execution on user's behalf
- Integration with broker APIs for direct trading
- Mobile app versions (iOS/Android native apps)
- Web dashboard interface outside Telegram
- Social trading features (copy trading, leaderboards)
- Multi-language support beyond English
- Voice/audio signal notifications
- Custom indicator creation by users
- Backtesting historical signals
- Live chat support within bot
- Referral program and affiliate system
- Advanced charting and visualization tools
- Integration with MetaTrader or other trading platforms
- Guaranteed profit promises or performance guarantees
